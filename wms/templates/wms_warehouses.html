怎么用

五级：仓库 → 区 → 货架 → 层 → 位。默认 7 个仓 （待检仓 / 可售仓 / 维修仓 / 报修仓 / 拆机件仓 / 危废区 / 退货暂存区）是系统内置的； 货品的「所在仓」取第 1 级，「货架位置」取第 2 级往后。其它页面（移库 / 出库 / 盘点 / 检测台） 里的仓库与库位**都从这里出下拉**，现场只能选、不能手打。

三条硬规矩：内置 7 仓不能删（分级路由按它入仓，可以改名 / 停用）； 编码与层级建好就不能改（货品、库存流水、批次、盘点单上都存着编码）—— 要换编码或换层级，就「停用旧的 + 新建一个」； 还在被引用的不能删（有下级 / 有货挂着 / 有批次 / 有盘点单），改用「停用」。
